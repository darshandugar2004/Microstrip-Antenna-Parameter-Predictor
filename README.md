# Predicting Microstrip Line Antenna Parameters Using FNN

This project involves designing a Feedforward Neural Network (FNN) model to predict microstrip line antenna parameters (Cut_x and Cut_y). The training data was generated by analyzing multiple antennas using Ansys.

## Project Overview
This project demonstrates the use of a neural network for predicting the inset feed lengths of microstrip line antennas based on input parameters such as frequency, substrate height, permittivity, and loss. The model was fine-tuned using GridSearchCV to find the best hyperparameters.

## Dataset
The dataset (`result.csv`) includes the following columns:
- `Freq`: Operating frequency of the antenna.
- `Height`: Height of the substrate.
- `Permitivity`: Dielectric constant of the substrate.
- `loss`: Dielectric loss tangent.
- `Cut_x`: Length of the inset feed in the x-direction (target).
- `Cut_y`: Width of the inset feed in the y-direction (target).

## Model Architecture
The FNN model has the following architecture:
1. Input layer with 8 neurons, ReLU activation.
2. Two hidden layers with 8 neurons each, ReLU activation.
3. Hidden layer with 16 neurons, ReLU activation.
4. Hidden layer with 32 neurons, ReLU activation.
5. Hidden layer with 64 neurons, ReLU activation.
6. Output layer with 1 neuron, linear activation.

The model uses the Adam optimizer and Mean Squared Error (MSE) as the loss function. A custom RMSE metric is also included for evaluation.

## Usage

1. Place the dataset `result.csv` in the project folder.

2. Run the script:
   ```bash
   python gridsearch_fnn.py
   ```

3. The script will perform the following:
   - Preprocess the data (standardization).
   - Define and train the FNN model for both `Cut_x` and `Cut_y` using GridSearchCV.
   - Evaluate the best models on the test set.
   - Save the best models as `best_model_x.keras` and `best_model_y.keras`.

## Results

- Root Mean Squared Error (RMSE)
